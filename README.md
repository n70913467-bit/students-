# Project Control Dashboard

A lightweight, responsive project and task tracking dashboard.

## Scope
- Track projects by Running, On Hold, Stopped, and Planned status.
- Record last activity, progress, next action, and approvals required.
- Add projects and tasks, mark tasks complete, and export project data as CSV.
- Track the eight-stage development roadmap.

## Explicit exclusions
This project does **not** process, collect, or manage payments. No payment gateway, UPI, card, wallet, banking, merchant, or payment API integration is in scope.

## Run locally
Open `index.html` in a modern browser. Data is saved in that browser's localStorage. This first version is a single-user local prototype; it is not yet a multi-user hosted application or server-backed database.
